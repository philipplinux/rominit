Jailbreak: where to start

An entry point is the first way to run community-made code on your console. Different routes use different apps, discs or browser features, and only work on certain firmware versions.

Deeper access: kernel & hypervisor

These projects unlock more of the console after the first entry point. That extra access can let homebrew use features Sony normally locks away. They are steps in a larger setup, rather than apps you simply install.

Run Linux on your PS5

Linux turns the console into a desktop-like computer for compatible software and emulators. You need a supported jailbreak route and usually a separate USB drive.

Homebrew apps & launchers

Once you have a working entry point, these tools help load, manage or run community-made apps. Check the setup notes to see which loader each one needs.

PLAY OTHER SYSTEMS

Emulation

Emulators let your PS5 play games made for other systems. Some run as PS5 homebrew; others need Linux installed first. The systems and setup needed are listed on each card. Performance varies by game. Want it the other way round? Play PS5 games on other devices ↓

EMULATION THE OTHER WAY

Play PS5 games on other devices

The reverse of the section above: instead of other systems on your PS5, your PS5 games on a computer, such as AnyPS5. These tools convert games you dumped from your own console. Nothing is installed on the PS5, but dumping a game needs a jailbroken console first. More in Emulators.

Firmware rollback & research

Rollback means going back to older system software, often to reach a jailbreak-compatible version. An old update file alone does not make that possible. Recovery reinstalls software; a backup may only work on the console it came from.

Restore the official system software

Use these links when the console needs Sony’s system software repaired or reinstalled. A full reinstall erases console data. Older files in an archive do not bypass Sony’s update restrictions.

Desktop, USB & development tools

A USB image writer prepares a drive; a payload sender uses an existing loader. Neither is automatically a PS5 firmware flasher.
