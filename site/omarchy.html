02 / BEFORE YOU INSTALL

Check the machine first

  • The current Omarchy manual says to disable Secure Boot and/or TPM in firmware to install.
  • Installation defaults to encryption. Full-disk installation erases the selected drive; free-space installation uses unallocated space.
  • Use a wired or 2.4 GHz keyboard for startup disk encryption; Bluetooth keyboards cannot enter that passphrase at boot.
  • USB writers erase the selected USB. Verify the drive and back up its contents before using the publisher’s instructions.

The current manual documents full-disk and free-space install choices. Older manuals may describe different dual-boot limits.
