# Captures

`robots.txt` is the literal HTML body returned for `https://xdaforums.com/robots.txt`, not a usable robots policy. `robots.meta.json` records the 403, request URL, final URL, response headers and UTC capture time. User-Agent: `ROMinit/0.1 (ROM release feed feasibility research)`. No follow-up XDA requests were made.

`github-robots.txt` is the literal GitHub robots response; its adjacent metadata file records status/headers/time. Its wildcard-agent group disallows `.atom` URLs; no direct GitHub feed request followed.

Other JSON files are Ketch search results, including index excerpts and provider errors, not live XDA captures. `search0`/`search1`: S7 edge/S9; `more0`: Mi A3; `more2`: S9+/cross-device; `pixel`: Pixel forums; `more3`: prefixes; `more4`: update/order behavior; `more5`: terms and editorial-host robots; `single-thread`: RSS importer discussion, not evidence of thread-feed export. `fields` is inconclusive importer-related material and does not establish XDA export fields. Empty/error result files are retained to make the research limits visible.

No XDA feed XML was obtained. No sample in this directory should be presented as a successful XDA RSS/Atom feed. Search-index timestamps and dates inside excerpts are not capture timestamps.
